# 🧠 브레인 어드벤처 (Brain Adventure)

미션 기반 점프 게임 - 퀴즈를 풀고 점프맵을 클리어하세요!

## 📖 게임 소개

브레인 어드벤처는 브레인 테스트 퀴즈와 점프맵을 결합한 독특한 플랫포머 게임입니다.
각 스테이지마다 먼저 퀴즈를 풀고, 정답을 맞춰야만 점프맵에 도전할 수 있습니다!

## ✨ 게임 특징

### 🎮 스테이지 시스템
- **총 70단계**의 다양한 난이도
- 브레인 테스트 퀴즈 풀이 후 점프맵 통과
- 퀴즈를 틀리면 통과 불가
- 난이도: Easy → Normal → Hard → Extreme

### 🎁 보상 시스템
- **2단계마다**: 아이템 랜덤 뽑기 기회 1번
- **30단계마다**: 힌트 3번 제공
- **매 스테이지**: 코인 획득 (스테이지가 높을수록 더 많이!)

### 🎒 아이템 시스템

**일반 아이템 (Common):**
- **스테이지 스킵**: 현재 스테이지를 건너뛸 수 있습니다
- **2단 점프 신발**: 공중에서 한 번 더 점프할 수 있습니다
- **힌트**: 브레인 테스트 문제의 힌트를 볼 수 있습니다

**레어 아이템 (Rare) - 날 수 있는 아이템:**
- **헬리콥터 모자**: 10초 동안 자유롭게 날 수 있습니다
- **풍선**: 10초 동안 자유롭게 날 수 있습니다

### 👔 커스터마이징 시스템

**기본 옷:**
- 청바지 (100 코인) - 기본 제공
- 반바지 (80 코인)
- 버섯 슈트 (200 코인)
- 갑옷 (500 코인)

**특별 옷:**
- 크리스마스 옷 (300 코인) - 시즌 한정
- 할로윈 옷 (300 코인) - 시즌 한정
- 동물 슈트 (250 코인)

### 🚪 특별 기능
- **Secret Door**: 30% 확률로 등장하는 숨겨진 문
- 비밀 문을 통과하면 **비밀 상점** 접근 가능
- 상점에서 코인으로 다양한 옷 구매 가능

## 🎯 캐릭터
- **졸라맨** 스타일의 귀여운 스틱맨 캐릭터

## 🕹️ 게임 플레이

1. **퀴즈 단계**: 브레인 테스트 문제를 풀어야 합니다
2. **정답 맞추기**: 4개의 선택지 중 정답을 선택하세요
3. **점프맵 클리어**: 퀴즈를 맞추면 점프맵이 등장합니다
4. **골 도달**: 플랫폼을 건너뛰어 골에 도달하세요
5. **보상 획득**: 2단계마다 아이템 뽑기, 30단계마다 힌트 3개 획득
6. **비밀 탐험**: Secret Door를 찾아 특별한 옷을 구매하세요!

## 🎮 조작법

- **← →**: 좌우 이동
- **↑**: 점프
- **I**: 인벤토리 열기
- **마우스**: UI 버튼 클릭

## 🚀 설치 및 실행

### 필요 요구사항
- Node.js (v14 이상)
- npm (v6 이상)

### 설치
```bash
cd brain-adventure
npm install
```

### 개발 모드 실행
```bash
npm start
```
브라우저에서 `http://localhost:8080`으로 접속하세요.

### 프로덕션 빌드
```bash
npm run build
```
빌드된 파일은 `dist` 폴더에 생성됩니다.

```

│   │   ├── InventorySystem.js # 인벤토리 관리
│   │   ├── GachaSystem.js    # 아이템 뽑기
│   │   └── StageSystem.js    # 스테이지 관리
│   ├── data/                 # 게임 데이터
│   │   ├── items.js          # 아이템 데이터
│   │   ├── costumes.js       # 옷 데이터
│   │   └── quizzes.js        # 퀴즈 데이터 (70개)
│   ├── config.js             # 게임 설정
```

## 🎨 기술 스택

- **게임 엔진**: Phaser 3
- **빌드 도구**: Webpack 5
- **개발 서버**: webpack-dev-server
- **언어**: JavaScript (ES6+)

## 💾 저장 시스템

게임은 브라우저의 `localStorage`를 사용하여 진행 상황을 자동으로 저장합니다:
- 현재 스테이지
- 클리어한 스테이지 목록
- 보유 아이템
- 코인 개수
- 보유한 옷
- 장착 중인 옷
- 힌트 개수
